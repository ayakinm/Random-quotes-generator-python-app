# Random Quotes Generator

A small Flask app that displays a random quote each time you visit or refresh the page.

## Run locally

1. Create and activate a virtual environment:

	```powershell
	python -m venv .venv
	.venv\Scripts\Activate.ps1
	```

2. Install Flask:

	```powershell
	python -m pip install -r requirements.txt
	```

3. Start the app:

	```powershell
	python app.py
	```

4. Open http://127.0.0.1:5000 in your browser. Refresh the page or select **Another thought** for a new random quote.
